# 身障/長照補助計算機 (Disability & Long-Term Care Subsidy Calculator)

這是一款專為一線輔具評估人員與治療師設計的 **「離線優先 (Offline-First)」智慧型補助試算工具 (PWA)**。本工具整合了身心障礙者生活輔具補助基準以及長照 2.0 輔具與居家無障礙環境改善服務，協助評估人員在實地家訪、社區評估或網路收訊不良的現場，仍能瞬間完成精確的雙軌補助額度試算、最優申請管道判斷，並提供一鍵分享螢幕截圖功能。

---

## 🚀 核心功能特色

### 1. 離線優先技術 (Offline-First PWA)
* **斷網秒開**：採用 Service Worker 靜態資源全快取技術，首次在有網路環境開啟後，系統骨架（React, Tailwind, html-to-image 等核心庫）會完全鎖入手機記憶體，在無訊號的案家、地下室或偏鄉也能一秒啟動。
* **本地備援資料庫**：平時開啟不經過網路請求，直接自 LocalStorage 讀取基準表，擺脫雲端連線造成的畫面轉圈與延遲。

### 2. 數據管理與智慧手動同步
* **掌控權移交**：點擊下方的「總清除」按鈕僅會進行 React 狀態歸零，**絕對不重新觸發網頁整理或重新同步雲端資料**，維持極致流暢感。
* **精確手動更新**：於主標題右上角設計「更新基準表」旋轉按鈕，並標記最後更新日期。僅在需要同步 Google 試算表最新修改或政府法規修訂時，由操作者主動點擊觸發，具備 12 秒連線超時防卡死保護。
* **強力數據清洗 (toNum)**：內建強健數值解析引擎，自動移除 Google 試算表匯出時產生的「千分位逗號（如 `2,520` 轉為 `2520`）」、中文字符（如「元」、「上限」）或前後空白，徹底根除格式混亂導致補助金額歸零的常見靈異現象。

### 3. 一線實務體驗優化 (Hand-feel UX)
* **組數輸入防錯**：改善無障礙項目組數輸入邏輯，刪除時允許暫時完全空白，輸入新數字時**自動消去前導零**，不再出現 `020` 或 `01` 等不符合直覺的輸入狀況。
* **點擊自動全選**：手指點擊或平板觸控組數欄位時，自動全選既有數值，可直接輸入新數值進行覆蓋，減少反覆按退格鍵的麻煩。
* **精確無障礙雙軌比對**：未選取任何無障礙項目時，智慧顯示「金額相同」；一旦選取，即時比對並以專用方框獨立顯示「長照較優 (+金額)」或「身障較優 (+金額)」，提供清楚的決策輔助。
* **額度警示防爆機制**：即時動態加總長照占用額度，若超過 `40,000` 元，儀表板小方塊將即時變色，並於下方渲染靜態黃底紅字超額警語。
* **完美一鍵截圖**：全面採用客製化 SVG 圖片型勾選框與單選鈕，取代瀏覽器原生表單元件。使用 `html-to-image` 進行快照時，能完美捕捉「即時勾選狀態」並輸出乾淨、端正的 PNG 圖檔，方便留存或傳送予案主。

## 📊 Google 試算表後台 CMS 設定規範

本 App 透過讀取發佈為 CSV 格式的 Google 試算表進行即時更新，各分頁（Tab）的欄位排列與起始行數具有嚴格的結構規範，請務必依循以下設定：

### 1. 生活輔具分頁 (`EQUIP`) — *從第 3 列 (Row 3) 開始為正式數據*
* **A 欄 (A3+)**：生活輔具項目名稱
* **B 欄 (B3+)**：身障一般戶補助金額
* **C 欄 (C3+)**：身障中低收補助金額
* **D 欄 (D3+)**：身障低收補助金額
* **E 欄 (E3+)**：長照一般戶補助金額
* **F 欄 (F3+)**：長照中低收補助金額
* **G 欄 (G3+)**：長照低收補助金額 (同時作為長照佔用額度基準)
* **H 欄 (H3+)**：年限

### 2. 身障無障礙分頁 (`DIS_CONST`) — *從第 2 列 (Row 2) 開始為正式數據*
* **A 欄 (A2+)**：項目名稱
* **B 欄 (B2+)**：身障一般戶補助金額
* **C 欄 (C2+)**：身障中低收補助金額
* **D 欄 (D2+)**：身障低收補助金額

### 3. 長照無障礙分頁 (`LTC_CONST`) — *從第 2 列 (Row 2) 開始為正式數據*
* **A 欄 (A2+)**：項目名稱
* **B 欄 (B2+)**：長照一般戶補助金額
* **C 欄 (C2+)**：長照中低收補助金額
* **D 欄 (D2+)**：長照低收補助金額 (同時作為單項額度基準)

*註：建議將 Google 試算表的儲存格格式設定為「純數字」，但即使不小心保留千分位逗點（如 `10,500`），App 內建的 `toNum` 強力清洗器也能自動過濾，不影響運算。*

## 📲 跨平台安裝指南 (Installation)

本工具為標準 PWA 應用，免上架、免下載 APK，iOS、Android 與電腦網頁端均能完美安裝。

### 🔹 iOS 裝置 (iPhone / iPad)
1.  使用 **Safari 瀏覽器** 開啟您的 GitHub Pages 計算機專屬網址。
2.  點擊瀏覽器底部的 **「分享」** 按鈕（一個方形帶有向上箭頭的圖示）。
3.  在彈出的選單中向下捲動，選擇 **「加入主畫面」 (Add to Home Screen)**。
4.  確認名稱後點擊右上角的「新增」，手機桌面即會出現精美的 App 圖示。

### 🔹 Android 裝置 (Google, Samsung, Sony 等)
1.  使用 **Chrome 瀏覽器** 開啟計算機網址。
2.  點擊網址列右側的 **「三個點」** 設定選單。
3.  在選單中選擇 **「安裝應用程式」** 或 **「新增至主畫面」**。
4.  依據系統提示確認安裝，稍等數秒後即可在手機桌面找到 App。

### 🔹 電腦網頁版 (Windows / Mac)
1.  使用 **Chrome** 或 **Edge** 瀏覽器開啟專屬網址。
2.  觀看網址列最右側，會出現一個類似「螢幕帶有向下箭頭」或「➕」的 **安裝圖示**。
3.  點擊該圖示並選擇「安裝」，系統會將其轉化為獨立視窗運作的桌面型應用程式。

## 🔄 系統更新機制 (How to Update)

本 App 的更新分為 **「基準表資料更新」** 與 **「程式邏輯/介面更新」** 兩種機制：

### 1. 基準表資料更新 (當法規或金額變動時)
* **機制**：直接在您的 Google 試算表後台修改數據。
* **如何同步**：請在**有網路**的狀態下，開啟 App，觀看頂部深藍色標題列右上角。點擊 **「旋轉箭頭圖示」**，系統將強制與雲端 CSV 重新對接，當跳出「基準表同步成功！」提示視窗後，最新數據便已寫入您的手機內存。之後即使斷網，使用的也是這份最新資料。

### 2. 程式邏輯與介面更新 (Code Level Update)
當開發團隊修改了網頁版面、修正了計算 Bug 或調整了按鈕外觀時，由於 Service Worker 的快取控制非常嚴格，手機端常會固守舊版快取。請嚴格執行以下更新步驟：
1.  **修改版本號**：在發佈更新代碼時，請打開專案中的 `service-worker.js`，將最上方的 `CACHE_NAME` 版本號進行遞增（例如：將 `v44` 改為 `v45`）。
2.  **手機端重置**：
    * **徹底大掃除**：如果您發現更新代碼後畫面出現全白，代表新舊快取產生衝突。請**先在桌面刪除該 App 的圖示**。
    * **瀏覽器清理**：打開手機瀏覽器，關閉所有計算機的分頁，重新輸入網址進入。
    * **重新加入**：進入網頁確認版面與版本號正確無誤、且點擊右上角同步按鈕顯示成功後，再重新將網頁 **「加入主畫面」**，即可享受最穩定的新功能。
3.  **電腦網頁端清理**：
    * 在全白的計算機畫面上按下 **`F12`** 打開開發者工具。
    * 切換至 **Application** (應用程式) 標籤 $
ightarrow$ 左側選單點擊 **Storage** (儲存空間)。
    * 點擊右側的主按鈕 **Clear site data** (清除站點資料)。
    * 重新整理網頁 (`F5`)，即可徹底抹除舊殘留，恢復正常運作。

## 🛠️ 技術堆疊與依賴項目
* **前端框架**：React 18 (Production) — 提供極速的高性能組件狀態管理。
* **解析編譯**：Babel Standalone — 實現 PWA 單檔案的高動態腳本解析。
* **樣式架構**：Tailwind CSS — 打造兼顧高密度資訊與行動端舒適點擊的 RWD 版面。
* **快照分享**：html-to-image 1.11.11 — 規避行動裝置截圖盲點，精確保存臨床評估數據。
* **架構模型**：Progressive Web App (PWA) — 透過前端快取實現完美跨平台三端（iOS、Android、Web）離線無縫操作。
